# KoliBri - Angular Template

This is a template for a KoliBri client side rendering application using Angular 21 with the Angular CLI application builder.

## Get Started

### Prerequisites

- [Node.js](https://nodejs.org/en/) 20+

### Installation

Install the dependencies using npm:

```bash
npm i # or pnpm i or yarn
```

### Usage

#### Start the development server

```bash
npm start
```

#### Build the application

```bash
npm run build
```

#### Lint the code

```bash
npm run lint
```

#### Format the code

```bash
npm run format
```

#### Check unused code and dependencies

```bash
npm run unused
```
