# KoliBri - SolidJS Template

This is a template for a KoliBri client side rendering application using SolidJS.

## Get Started

### Prerequisites

- [Node.js](https://nodejs.org/en/)

### Installation

Install the dependencies using pnpm:

```bash
pnpm i # or npm i or yarn
```

### Usage

#### Start the development server

```bash
npm start
```

#### Build the application

```bash
npm run build
```

#### Lint the code

```bash
npm run lint
```

#### Format the code

```bash
npm run format
```

#### Check unused code and dependencies

```bash
npm run unused
```
